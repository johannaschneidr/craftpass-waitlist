# CraftPass Waitlist 🖌️✨

**CraftPass** is like ClassPass, but for arts & crafts workshops. This is the landing page to gather early signups from creative humans who want to explore, book, and fall in love with workshops—from pottery to painting, and everything in between.  

Built on top of a template by [lakshaybhushan](https://github.com/lakshaybhushan) (though you probably wouldn’t recognize it now 😉), this landing page is **heavily vibe coded** and designed to convert curious creatives into early adopters.  

---

## What It Does

- 🎨 Collects email signups for the CraftPass waitlist  
- ✨ Presents a clean, inviting, and playful interface  
- 🖌 Engages users with simple, creative vibes to reflect the arts & crafts world  

---

## Tech Stack

- **Frontend:** TypeScript (95.1%)  
- **Styling:** CSS (4.4%)  
- **Extras:** Minimal JavaScript (0.5%)
